# Плейбуки пишет модель, код пишет человек

Процедурная память системы — это файл. «Система научилась делать X» означает, что появился
`SKILL.md`, который загрузчик подхватит без единой строки изменений в ядре. Поэтому Директор
получает инструмент `write_skill(name, description, instructions)`: он сам записывает плейбук
по горячим следам задачи, которую только что решил.

**Генерации `tools.py` не будет.** Модель, пишущая исполняемый Python, который загрузчик тут же
импортирует, — это выполнение произвольного кода; закрыть его можно только песочницей, а это
ровно тот «большой сложный компонент», против которого написан `TASK.md`. Граница проведена по
безопасности: текст пишет модель, код пишет человек. По той же причине `write_skill` отказывается
переписывать скилл, у которого есть `tools.py`, — его инструкции несут ограничения, под которыми
выданы права на хост.

**Подтверждение обязательно** (`Safety.DANGEROUS`). Результат работы спавнутого агента попадает
в контекст Директора, а часть навыков возвращает недоверенный текст. Без подтверждения внедрённая
в такой текст инструкция могла бы записать плейбук — то есть отравить систему навсегда, а не на
одну задачу. Шлюз в Telegram уже есть, цена решения — ноль.

**Детектор повторов удалён** (`app/learning/detector.py`, `CandidateStore`, настройки `LEARN_MIN_*`).
Он существовал, чтобы предложить человеку сделать скилл из повторяющихся задач в журнале — а это
угадывание метода задним числом по интентам и трассам. Директор, который только что решил задачу,
знает её метод точно и без вызова LLM на анализ журнала. Отложенная в ADR 0002 «кристаллизация
повторов» закрыта не автогенерацией из журнала, а решением по горячим следам; опасение о дублях
способностей снимается тем, что список навыков у Директора перед глазами в момент записи.
Самопроверка (`/learn`, тик мониторинга) осталась: lint устаревших фактов, с `0006` — ещё и консолидация.

**Длина плейбука ограничена механически** (6000 символов). Плейбук уходит в промпт агента при
каждом spawn — это цена в токенах на всю его дальнейшую жизнь. Просьбу «пиши коротко» слабая
модель игнорирует, как уже показал бюджет вызовов недоверенных скиллов.

*Обновлено 16.09.2026: формат Agent Skills добавил скиллам `scripts/`. Границу это не сдвигает — скрипты кладёт человек вместе со скиллом, `write_skill` пишет только `SKILL.md`, а запуск скрипта (`run_skill_script`) идёт через подтверждение.*
