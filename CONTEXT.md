# Агентская система

Универсальный персональный помощник: один долгоживущий Директор получает задачи в Telegram и собирает под каждую задачу временных агентов из библиотеки скиллов. Инфраструктура VPN — первый сценарий использования, а не предмет системы.

## Язык

### Агенты

**Директор**:
Единственный постоянный агент. Разбирает задачу, выдаёт работу временным агентам, отвечает пользователю и один владеет памятью.
_Avoid_: оркестратор, координатор, менеджер

**Временный агент**:
Агент, созданный под одну задачу и уничтоженный вместе с контекстом после ответа. Роли заранее не существует — её задаёт выданный набор скиллов.
_Avoid_: специалист, воркер, субагент, сисадмин/программист/маркетолог

**Спавн**:
Акт создания временного агента: роль одной фразой, набор скиллов, задача. Несколько спавнов в одном ответе выполняются параллельно.

### Способности

**Скилл**:
Единица способности системы, живущая в отдельном каталоге. Добавляется и удаляется файлами, без правки кода.

**Плейбук**:
Текстовая часть скилла — стратегия, когда и как применять способность. Попадает в промпт временного агента только при выдаче скилла.

**Инструмент**:
Одна вызываемая функция с типизированными параметрами. Несёт собственную классификацию риска.

**Доступ к хосту**:
Полномочия на выполнение команд на сервере, которые скилл декларирует в файле. При спавне доступы выданных скиллов объединяются.

**Недоверенный источник**:
Скилл, чей вывод содержит текст, который система не контролирует (веб-страница, чужой API). Не может быть выдан агенту вместе с доступом к хосту.

### Память

**Оглавление**:
Верхний, дешёвый слой памяти в промпте Директора: перечень областей и их объём, но не содержимое. По нему принимается решение, куда углубляться.
_Avoid_: индекс, верхушка айсберга

**Факт**:
Устойчивое знание об окружении — топология, пути, версии, принятые решения. Живёт в области (`scope`) и перезаписывается по ключу.
_Avoid_: знание, запись памяти

**Эпизод**:
След одной завершённой задачи: что просили, чем закончилось, какими скиллами, получилось ли. Отвечает на вопрос «как я решал это в прошлый раз».
_Avoid_: история, лог, опыт

**Диалог**:
Недавние сообщения одного чата, ограниченные бюджетом токенов. Рабочая память Директора, не разделяемая с временными агентами.

**Плейбук**:
Скилл без кода — один `SKILL.md` с описанием способа работы поверх уже существующих навыков. Директор пишет его сам через `write_skill`; это и есть процедурная память системы.
_Avoid_: инструкция, шаблон, сценарий

### Взаимодействие

**Шлюз подтверждений**:
Механизм, останавливающий опасный вызов до явного решения человека в Telegram.
_Avoid_: veto, HITL, аппрув

**Отчёт**:
Ответ, оформленный файлом markdown и отправленный документом, когда пользователь просит «оформить».
